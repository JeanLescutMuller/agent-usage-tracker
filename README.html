agent-usage-tracker

Records Claude Code usage over time - quota percent, tokens, Claude Code's own $ - from every source that keeps no history of its own, on the MacBook and the VM H-Frank-1, in four categories of data. Codex keeps its own jobs, outside the four (design/CODEX_DESIGN.md). Last updated 2026-10-11 (the design built on 2026-10-10: design/TARGET_SPEC.md).

Which 5-min slots are final: a request is counted once its first line is ≥ 15 min old (all lines of one request are written within 292 s, measured). Each run of the aggregates job records "complete up to" = run time − 15 min; every slot ending before it is final, and only final slots are written, and sent. A Mac asleep from 22:00 to 08:00 writes and sends nothing meanwhile, then at its first run after waking every slot up to 07:45.

6 · Contract with agent-statusline

The two projects share exactly two files, each written by one side only; neither writes into the other's tree, and each works without the other.

InterfaceWritten byRead byWhat
~/opt/agent-usage-tracker/src/statusline_payload_reader.pythis repo (deployed, executable; install.sh writes its first line, this machine's python with -S, and its machine name)agent-statusline's Claude provider runs it on every rendertakes the raw payload (which fields it keeps is this repo's business), stores the reading, then prints the account's freshest one - the view latest: any session, poller or machine, the reset rule applied - as one line of six \034-separated fields, five_pct five_reset week_pct week_reset source observed_at. Always exits 0; no line: the status line shows its own session's reading
~/opt/agent-statusline/state/heartbeat/{claude,codex}agent-statusline, every renderclaude-quota.sh, codex_quota_api_poller.pyonly the mtime: a status line is on screen

Without agent-statusline there are no statusline readings: Claude Code runs a single statusLine command. The quota then comes from the poller only, and there are no session snapshots. Until 2026-10-10: bin/ingest-claude-statusline.sh and a state/quota/claude file.
