5 · Limits

Machines. Run on the VM, the scripts see both machines' slots; run on the Mac, the Mac's only. The VM's own Claude use is small (41 slots).
$ coverage. A $ exists only where Claude Code sent telemetry: none before 2026-09-30, none for Agent SDK sessions. B is fitted only where ≤ 5% of the tokens lack one.
Resolution. The % moves in 1% steps, 5-hour ends snap to 10 min, a slot is 5 min (its $ counts at its middle).
Samples. Max 5x: 7 windows at 30% or more, one full week.
